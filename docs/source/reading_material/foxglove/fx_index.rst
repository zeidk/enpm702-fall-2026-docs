====================================================
Foxglove
====================================================

Overview
--------

Foxglove is a program that draws what your ROS 2 nodes publish: the robot
in 3D, the camera image, plots of numbers, and the raw messages. This
reading material explains what Foxglove is, how to install it, how to
connect it to the ROSbot simulation of GP2, and how to load a ready-made
layout that shows the simulation's topics. It is a self-study reading
module, with no video.

.. note::

   **This reading is optional.** No assignment, quiz or exam needs
   Foxglove. GP2 uses only what the lectures teach. Try it outside class if
   you want a clearer view of the topics that you publish and subscribe to.


.. admonition:: Learning Objectives
   :class: learning-objectives

   By the end of this material, you will be able to:

   - Say what **Foxglove** and the **Foxglove bridge** are, and which
     program does which job.
   - Install the bridge for ROS 2 Jazzy and the Foxglove app.
   - Start the ROSbot simulation and the bridge, and open a connection to
     ``ws://localhost:8765``.
   - Load the course **layout** and read each of its four panels: 3D,
     Image, Plot and Raw Messages.
