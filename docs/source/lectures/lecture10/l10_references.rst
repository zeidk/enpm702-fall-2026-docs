        **ENPM702 L10: ROS 2 Foundations**

        The three ways nodes talk, the computation graph, publish and subscribe with its four rules and four patterns, running and inspecting nodes, the files of a package (``package.xml``, ``CMakeLists.txt``), a first node as a function and as a class, spinning, messages, and a publisher and a subscriber on a robotaxi fleet. The background (what ROS 2 is, DDS, nodes and processes, the workspace, ``colcon``) is in the Pre-Reading part of the :doc:`l10_lecture`.

        **Before next class**: complete the L10 exercises and quiz, and build and run ``robotaxi_demo`` in your own workspace.
