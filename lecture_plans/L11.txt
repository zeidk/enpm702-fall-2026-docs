            <h3><i class="icon-rubric-dark"><span class="dp-icon-content" style="display: none;">&nbsp;</span></i>Unit Objectives</h3>
            <p>This lecture covers the tools and techniques for configuring, launching, and orchestrating ROS 2 systems. It begins with parameters, node-specific configuration values that change behavior without recompiling, then explores launch files for starting multiple nodes. It examines executors, the mechanism that controls how callbacks are dispatched, and covers YAML configuration files and ROS 2 CLI tools for parameters.</p>
            <p class="whitespace-normal break-words">By the end of Lecture 11, students will be able to:</p>
            <ul class="[&amp;:not(:last-child)_ul]:pb-1 [&amp;:not(:last-child)_ol]:pb-1 list-disc space-y-1.5 pl-7">
                <li class="whitespace-normal break-words">Declare, get, and set parameters on ROS 2 nodes using <code>rclcpp</code></li>
                <li class="whitespace-normal break-words">Use parameter callbacks to respond when parameters change at runtime</li>
                <li class="whitespace-normal break-words">Write Python launch files to start multiple nodes with parameters, remappings, and arguments</li>
                <li class="whitespace-normal break-words">Use launch arguments (<code>DeclareLaunchArgument</code>, <code>LaunchConfiguration</code>) for reusable launch files</li>
                <li class="whitespace-normal break-words">Structure YAML configuration files and load them from launch files</li>
                <li class="whitespace-normal break-words">Distinguish single-threaded and multi-threaded executors and choose the appropriate one</li>
                <li class="whitespace-normal break-words">Use callback groups (mutually exclusive and reentrant) to control concurrency</li>
            </ul>
