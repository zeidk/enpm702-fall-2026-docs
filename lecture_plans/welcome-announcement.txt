            <h3><i class="far fa-clipboard" aria-hidden="true"><span class="dp-icon-content" style="display: none;">&nbsp;</span></i> Get Ready Before the First Class</h3>
            <p class="whitespace-normal break-words">All setup instructions live on the course documentation site. Work through them there:</p>
            <p class="whitespace-normal break-words">&rarr; <strong>Course documentation:</strong> <a class="inline_disabled" title="Link" href="https://enpm702-fall-2026-docs.readthedocs.io/en/latest/index.html" target="_blank" rel="noopener">https://enpm702-fall-2026-docs.readthedocs.io/en/latest/index.html</a></p>
            <ol class="[&amp;:not(:last-child)_ul]:pb-1 [&amp;:not(:last-child)_ol]:pb-1 list-decimal space-y-1.5 pl-7">
                <li class="whitespace-normal break-words"><strong>Read the syllabus</strong>
                    <ul class="[&amp;:not(:last-child)_ul]:pb-1 [&amp;:not(:last-child)_ol]:pb-1 list-disc space-y-1.5 pl-7">
                        <li class="whitespace-normal break-words">Review the grading, schedule, and course policies. <strong>Note:</strong> the syllabus PDF will be uploaded to Canvas at a later time.</li>
                    </ul>
                </li>
                <li class="whitespace-normal break-words"><strong>Install Ubuntu</strong>
                    <ul class="[&amp;:not(:last-child)_ul]:pb-1 [&amp;:not(:last-child)_ol]:pb-1 list-disc space-y-1.5 pl-7">
                        <li class="whitespace-normal break-words">Install <strong>Ubuntu 24.04 LTS (Noble Numbat)</strong> &mdash; recommended &mdash; or <strong>22.04 LTS (Jammy Jellyfish)</strong>. See the <a class="underline" href="https://ubuntu.com/tutorials/install-ubuntu-desktop" target="_blank" rel="noopener">official install guide</a>.</li>
                    </ul>
                </li>
                <li class="whitespace-normal break-words"><strong>Set up Git and GitHub</strong>
                    <ul class="[&amp;:not(:last-child)_ul]:pb-1 [&amp;:not(:last-child)_ol]:pb-1 list-disc space-y-1.5 pl-7">
                        <li class="whitespace-normal break-words">Create a <a class="underline" href="https://github.com" target="_blank" rel="noopener">GitHub account</a> (use a professional username) and verify your email.</li>
                        <li class="whitespace-normal break-words">Install Git, configure your name/email, and set up SSH authentication.</li>
                        <li class="whitespace-normal break-words">Work through the <a class="underline" href="https://enpm702-fall-2026-docs.readthedocs.io/en/latest/reading_material/version_control/vc_index.html" target="_blank" rel="noopener"><strong>Version Control (Git and GitHub)</strong></a> reading module.</li>
                    </ul>
                </li>
                <li class="whitespace-normal break-words"><strong>Install and configure Visual Studio Code</strong>
                    <ul class="[&amp;:not(:last-child)_ul]:pb-1 [&amp;:not(:last-child)_ol]:pb-1 list-disc space-y-1.5 pl-7">
                        <li class="whitespace-normal break-words">Install <a class="underline" href="https://code.visualstudio.com/download" target="_blank" rel="noopener">VSCode</a> on Ubuntu.</li>
                        <li class="whitespace-normal break-words">Install the recommended extensions: <strong>C/C++</strong>, <strong>CMake Tools</strong>, <strong>CMake</strong>, <strong>Doxygen Documentation Generator</strong>, <strong>Error Lens</strong>, and <strong>GitLens</strong>.</li>
                        <li class="whitespace-normal break-words">Follow the <a class="underline" href="https://enpm702-fall-2026-docs.readthedocs.io/en/latest/reading_material/vscode_cmake/vcm_index.html" target="_blank" rel="noopener"><strong>VSCode and CMake</strong></a> reading module to set up the <code class="bg-text-200/5 border border-0.5 border-border-300 text-danger-000 whitespace-pre-wrap rounded-[0.4rem] px-1 py-px text-[0.9rem]">.vscode</code> folder and build a hello-world CMake project.</li>
                    </ul>
                </li>
                <li class="whitespace-normal break-words"><strong>Work through the Linux Shell module</strong>
                    <ul class="[&amp;:not(:last-child)_ul]:pb-1 [&amp;:not(:last-child)_ol]:pb-1 list-disc space-y-1.5 pl-7">
                        <li class="whitespace-normal break-words">Complete the <a class="underline" href="https://enpm702-fall-2026-docs.readthedocs.io/en/latest/reading_material/linux_shell/ls_index.html" target="_blank" rel="noopener"><strong>Linux Shell</strong></a> reading module (shell types, configuration files, aliases, and functions).</li>
                    </ul>
                </li>
                <li class="whitespace-normal break-words"><strong>Clone the course C++ repository and build the Lecture 1 code</strong>
                    <ul class="[&amp;:not(:last-child)_ul]:pb-1 [&amp;:not(:last-child)_ol]:pb-1 list-disc space-y-1.5 pl-7">
                        <li class="whitespace-normal break-words">Clone it: <code class="bg-text-200/5 border border-0.5 border-border-300 text-danger-000 whitespace-pre-wrap rounded-[0.4rem] px-1 py-px text-[0.9rem]">git clone https://github.com/zeidk/enpm702-fall-2026-cpp.git ~/enpm702-cpp</code></li>
                        <li class="whitespace-normal break-words">Source the helper script (<code class="bg-text-200/5 border border-0.5 border-border-300 text-danger-000 whitespace-pre-wrap rounded-[0.4rem] px-1 py-px text-[0.9rem]">enpm702-cpp.sh</code>), run <code class="bg-text-200/5 border border-0.5 border-border-300 text-danger-000 whitespace-pre-wrap rounded-[0.4rem] px-1 py-px text-[0.9rem]">enpm702</code>, then build with <code class="bg-text-200/5 border border-0.5 border-border-300 text-danger-000 whitespace-pre-wrap rounded-[0.4rem] px-1 py-px text-[0.9rem]">702configure</code> and <code class="bg-text-200/5 border border-0.5 border-border-300 text-danger-000 whitespace-pre-wrap rounded-[0.4rem] px-1 py-px text-[0.9rem]">702build</code>.</li>
                        <li class="whitespace-normal break-words">Run the Lecture 1 executable to confirm your toolchain works: <code class="bg-text-200/5 border border-0.5 border-border-300 text-danger-000 whitespace-pre-wrap rounded-[0.4rem] px-1 py-px text-[0.9rem]">~/enpm702-cpp/build/src/lecture1/lecture1</code></li>
                        <li class="whitespace-normal break-words">Full instructions are in the <strong>Lecture 1 Pre-Work</strong> on Canvas.</li>
                    </ul>
                </li>
            </ol>
