            <h3><i class="icon-rubric-dark"><span class="dp-icon-content" style="display: none;">&nbsp;</span></i>Unit Objectives</h3>
            <p>This lecture covers the Standard Template Library (STL) containers, strings, arrays, and vectors. Students learn about container memory management, access and modification patterns, and iterators. By understanding how the STL organizes and manages data, students can choose the right container for a task and use it effectively.</p>
            <p class="whitespace-normal break-words">By the end of Lecture 4, students will be able to:</p>
            <ul class="[&amp;:not(:last-child)_ul]:pb-1 [&amp;:not(:last-child)_ol]:pb-1 list-disc space-y-1.5 pl-7">
                <li class="whitespace-normal break-words">Describe the STL and its role in the C++ Standard Library, including the four categories of containers</li>
                <li class="whitespace-normal break-words">Distinguish C-style strings from <code>std::string</code> and explain why <code>std::string</code> is preferred</li>
                <li class="whitespace-normal break-words">Perform common string operations: initialization, concatenation, insertion, removal, and searching</li>
                <li class="whitespace-normal break-words">Compare <code>std::array</code> with C-style arrays and use multidimensional arrays</li>
                <li class="whitespace-normal break-words">Use <code>std::vector</code> for dynamic arrays with automatic memory management</li>
                <li class="whitespace-normal break-words">Use iterators to traverse containers and understand the iterator abstraction</li>
                <li class="whitespace-normal break-words">Explain container memory management: capacity, size, <code>reserve()</code>, and <code>shrink_to_fit()</code></li>
            </ul>
