            <h3><i class="icon-rubric-dark"><span class="dp-icon-content" style="display: none;">&nbsp;</span></i>Unit Objectives</h3>
            <p>This lecture introduces the foundations of Object-Oriented Programming (OOP) in C++. It begins with the core principles, encapsulation, abstraction, inheritance, and polymorphism, then walks through the development cycle: requirement analysis, UML modeling, and implementation. Students learn to define classes with proper encapsulation, write accessors and mutators with <code>const</code>-correctness, construct objects with member initializer lists, and work with the <code>this</code> pointer and <code>static</code> members.</p>
            <p class="whitespace-normal break-words">By the end of Lecture 8, students will be able to:</p>
            <ul class="[&amp;:not(:last-child)_ul]:pb-1 [&amp;:not(:last-child)_ol]:pb-1 list-disc space-y-1.5 pl-7">
                <li class="whitespace-normal break-words">Understand the core principles of OOP (encapsulation, abstraction, inheritance, polymorphism)</li>
                <li class="whitespace-normal break-words">Define and implement classes with proper encapsulation using access specifiers</li>
                <li class="whitespace-normal break-words">Create default and parameterized constructors with member initializer lists</li>
                <li class="whitespace-normal break-words">Implement accessors and mutators with proper <code>const</code>-correctness</li>
                <li class="whitespace-normal break-words">Apply modern C++ features: <code>std::string_view</code>, <code>std::optional</code>, <code>[[nodiscard]]</code>, and <code>noexcept</code></li>
                <li class="whitespace-normal break-words">Understand the <code>this</code> pointer and use <code>static</code> data members and member functions</li>
            </ul>
