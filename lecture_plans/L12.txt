            <h3><i class="icon-rubric-dark"><span class="dp-icon-content" style="display: none;">&nbsp;</span></i>Unit Objectives</h3>
            <p>This lecture extends the ROS 2 toolkit beyond publish-subscribe by introducing two additional communication patterns: services and actions. Services provide a synchronous request-response mechanism for quick queries and commands, while actions support long-running tasks that report incremental feedback and can be preempted. Students define custom <code>.srv</code> and <code>.action</code> interfaces, implement servers and clients in C++, and learn when each pattern is appropriate.</p>
            <p class="whitespace-normal break-words">By the end of Lecture 12, students will be able to:</p>
            <ul class="[&amp;:not(:last-child)_ul]:pb-1 [&amp;:not(:last-child)_ol]:pb-1 list-disc space-y-1.5 pl-7">
                <li class="whitespace-normal break-words">Distinguish the three core communication patterns: topics, services, and actions</li>
                <li class="whitespace-normal break-words">Define custom service interfaces (<code>.srv</code> files) and build them with <code>ament_cmake</code></li>
                <li class="whitespace-normal break-words">Implement a service server using <code>create_service</code> and handle requests in a callback</li>
                <li class="whitespace-normal break-words">Implement a service client using <code>create_client</code> and <code>async_send_request</code></li>
                <li class="whitespace-normal break-words">Define custom action interfaces (<code>.action</code> files) and build them with <code>ament_cmake</code></li>
                <li class="whitespace-normal break-words">Implement an action server using <code>rclcpp_action</code> that publishes feedback and returns a result</li>
                <li class="whitespace-normal break-words">Implement an action client that sends goals, receives feedback, and processes results asynchronously</li>
            </ul>
