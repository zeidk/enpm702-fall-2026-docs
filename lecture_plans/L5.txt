            <h3><i class="icon-rubric-dark"><span class="dp-icon-content" style="display: none;">&nbsp;</span></i>Unit Objectives</h3>
            <p>This lecture introduces the fundamental building blocks of modular C++ programming: functions. Students learn to declare, define, and call functions, how data flows in and out through parameter-passing mechanisms, and how to organize code using header files. The lecture also covers function overloading, default parameters, static variables, the call stack, recursion, and documentation with Doxygen.</p>
            <p class="whitespace-normal break-words">By the end of Lecture 5, students will be able to:</p>
            <ul class="[&amp;:not(:last-child)_ul]:pb-1 [&amp;:not(:last-child)_ol]:pb-1 list-disc space-y-1.5 pl-7">
                <li class="whitespace-normal break-words"><strong>Explain</strong> function fundamentals: declarations, definitions, calls, and the benefits of modularity</li>
                <li class="whitespace-normal break-words"><strong>Select</strong> appropriate methods for passing data to functions (by-value, by-reference, by-pointer) and returning data</li>
                <li class="whitespace-normal break-words"><strong>Implement</strong> enhanced features: function overloading, default parameters, and static variables</li>
                <li class="whitespace-normal break-words"><strong>Describe</strong> the execution model: the call stack, stack frames, and recursion</li>
                <li class="whitespace-normal break-words"><strong>Apply</strong> best practices for documentation with Doxygen and handle command-line arguments in <code>main()</code></li>
            </ul>
