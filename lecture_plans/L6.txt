            <h3><i class="icon-rubric-dark"><span class="dp-icon-content" style="display: none;">&nbsp;</span></i>Unit Objectives</h3>
            <p>This lecture builds on the function fundamentals from Lecture 5 and introduces advanced features of C++ functions. It begins with <code>struct</code> and aggregate initialization, then moves into templates for generic, reusable code. The lecture covers function operators (<code>decltype</code>), specifiers (<code>constexpr</code>, <code>inline</code>, <code>noexcept</code>), and attributes, and explores callables: function pointers, functors, lambdas, and <code>std::function</code>.</p>
            <p class="whitespace-normal break-words">By the end of Lecture 6, students will be able to:</p>
            <ul class="[&amp;:not(:last-child)_ul]:pb-1 [&amp;:not(:last-child)_ol]:pb-1 list-disc space-y-1.5 pl-7">
                <li class="whitespace-normal break-words"><strong>Use struct</strong>: aggregate initialization and structured bindings</li>
                <li class="whitespace-normal break-words"><strong>Write generic code</strong>: function templates, type deduction, and specialization</li>
                <li class="whitespace-normal break-words"><strong>Apply type inspection</strong>: the <code>decltype</code> operator and trailing return types</li>
                <li class="whitespace-normal break-words"><strong>Apply function specifiers</strong>: <code>constexpr</code>, <code>inline</code>, and <code>noexcept</code></li>
                <li class="whitespace-normal break-words"><strong>Apply function attributes</strong>: <code>[[nodiscard]]</code>, <code>[[maybe_unused]]</code>, <code>[[deprecated]]</code></li>
                <li class="whitespace-normal break-words"><strong>Master callables</strong>: function pointers, functors, lambdas, and <code>std::function</code></li>
            </ul>
