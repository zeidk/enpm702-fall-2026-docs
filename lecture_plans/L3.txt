            <h3><i class="icon-rubric-dark"><span class="dp-icon-content" style="display: none;">&nbsp;</span></i>Unit Objectives</h3>
            <p>This lecture covers memory allocation types, raw pointers, references, and dynamic memory management. Students learn to declare, initialize, and use pointers safely, understand const-correctness, and recognize common pitfalls. Valgrind is introduced for memory debugging.</p>
            <p class="whitespace-normal break-words">By the end of Lecture 3, students will be able to:</p>
            <ul class="[&amp;:not(:last-child)_ul]:pb-1 [&amp;:not(:last-child)_ol]:pb-1 list-disc space-y-1.5 pl-7">
                <li class="whitespace-normal break-words">Identify and explain the three types of memory allocation: static, automatic, and dynamic</li>
                <li class="whitespace-normal break-words">Declare, initialize, and use raw pointers, including the address-of (<code>&amp;amp;</code>) and dereference (<code>*</code>) operators</li>
                <li class="whitespace-normal break-words">Apply const-correctness to pointers (pointer-to-const, const-pointer, and const-pointer-to-const)</li>
                <li class="whitespace-normal break-words">Allocate and deallocate memory dynamically using <code>new</code> and <code>delete</code></li>
                <li class="whitespace-normal break-words">Recognize common pointer pitfalls: dangling pointers, memory leaks, double delete, and null dereferencing</li>
                <li class="whitespace-normal break-words">Distinguish between references and pointers and know when to use each</li>
                <li class="whitespace-normal break-words">Use Valgrind to detect memory leaks and memory errors in C++ programs</li>
            </ul>
