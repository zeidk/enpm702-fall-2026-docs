            <h3><i class="icon-rubric-dark"><span class="dp-icon-content" style="display: none;">&nbsp;</span></i>Unit Objectives</h3>
            <p>This is the first ROS 2 lecture in ENPM702. Students learn the core communication pattern in ROS 2: the publish-subscribe model. The lecture covers creating packages with <code>colcon</code>, writing publisher and subscriber nodes in C++ (inheriting from <code>rclcpp::Node</code>), working with standard message types, and defining custom interfaces. By the end, students can build, run, and inspect ROS 2 nodes that communicate over topics.</p>
            <p class="whitespace-normal break-words">By the end of Lecture 10, students will be able to:</p>
            <ul class="[&amp;:not(:last-child)_ul]:pb-1 [&amp;:not(:last-child)_ol]:pb-1 list-disc space-y-1.5 pl-7">
                <li class="whitespace-normal break-words">Understand the ROS 2 architecture: nodes, topics, messages, and the computation graph</li>
                <li class="whitespace-normal break-words">Create ROS 2 packages using <code>ros2 pkg create</code> with <code>ament_cmake</code></li>
                <li class="whitespace-normal break-words">Build packages with <code>colcon build</code> and source the overlay workspace</li>
                <li class="whitespace-normal break-words">Write publisher and subscriber nodes that inherit from <code>rclcpp::Node</code></li>
                <li class="whitespace-normal break-words">Use standard message types (<code>std_msgs</code>, <code>geometry_msgs</code>)</li>
                <li class="whitespace-normal break-words">Define custom message types (<code>.msg</code> files) in a dedicated interface package</li>
                <li class="whitespace-normal break-words">Use ROS 2 CLI tools to inspect the system (<code>ros2 topic</code>, <code>ros2 node</code>)</li>
            </ul>
