        <h3 class="" style="background-color: #990000; color: #ffffff; margin-top: 0px; margin-bottom: 0px;">Course Overview</h3>
        <div style="padding: 10px 15px;">
            <p>ENPM702 teaches modern C++ programming for robotics, progressing from core language fundamentals to building complete robotic systems with ROS 2 and Gazebo.</p>
            <p><strong>Part 1 &mdash; C++ Foundations (Weeks 1&ndash;9):</strong> You will learn the building blocks of C++ &mdash; variables, types, pointers, memory management, STL containers, functions, templates, lambdas, smart pointers, and object-oriented programming (classes, inheritance, polymorphism). Each concept is practiced through cumulative Real-World Application (RWA) assignments that progressively build a robotics-themed C++ application.</p>
            <p><strong>Part 2 &mdash; ROS 2 &amp; Gazebo (Weeks 10&ndash;15):</strong> You will apply your C++ skills within the Robot Operating System (ROS 2) framework. Topics include publishers, subscribers, custom interfaces, parameters, launch files, services, actions, coordinate frames (TF2), and lifecycle nodes. Through cumulative Group Projects (GPs), your team will build a multi-node robotic system controlling a mobile robot in Gazebo simulation.</p>
            <p>By the end of the course, you will be able to design, implement, and deploy C++ applications for robotic systems &mdash; from managing memory safely with smart pointers to orchestrating multi-robot coordination through ROS 2.</p>
        </div>
    </div>
    <div class="dp-content-block kl_custom_block_4" style="padding: 0px;">
        <h3 class="" style="margin-top: 0px; margin-bottom: 0px; background-color: #990000; color: #ffffff;">Course Outcomes</h3>
        <div style="padding: 10px 15px;">
            <p>After successfully completing this course, students will be able to:</p>
            <ol style="list-style-type: decimal;">
                <li><strong>Write correct and efficient C++ programs</strong> using variables, types, constants, namespaces, and modern initialization practices (C++17 and beyond).</li>
                <li><strong>Manage memory safely</strong> using pointers, references, smart pointers (<code>unique_ptr</code>, <code>shared_ptr</code>, <code>weak_ptr</code>), and RAII principles &mdash; eliminating memory leaks and undefined behavior.</li>
                <li><strong>Use the Standard Template Library</strong> (strings, arrays, vectors, iterators) and write reusable code with function templates, lambdas, and <code>std::function</code>.</li>
                <li><strong>Design object-oriented systems</strong> using classes, encapsulation, inheritance, polymorphism, and abstract interfaces to build modular and extensible software.</li>
                <li><strong>Develop ROS 2 applications</strong> using publishers, subscribers, services, actions, custom interfaces, parameters, launch files, and executors.</li>
                <li><strong>Build and simulate robotic systems</strong> in Gazebo, including coordinate frame management (TF2) and lifecycle node orchestration for production-quality deployments.</li>
            </ol>
